# A scheduled task for the repo

`B15.cloud-routine`

A script starts a cloud session only by firing a scheduled task's API trigger (formerly a routine, GH-69). The scheduled task holds the repo, the model and the environment; the Command Center sends each task in the fire's text.

## How to fix it

Do it opens Set up cloud builders, at The scheduled task: Copy the prompt, then Open claude.ai. There, paste it as a new scheduled task's instructions, pick this repo and a model, and add an API trigger. Paste its trigger id (trig_…) and click Keep the id.

More detail: [Claude Code docs](https://code.claude.com/docs/en/routines)

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
