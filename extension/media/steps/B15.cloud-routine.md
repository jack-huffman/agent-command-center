# A routine for the repo

`B15.cloud-routine`

A script starts a cloud session only by firing a routine's API trigger (GH-69). The routine holds the repo, the model and the environment; the Command Center sends each task in the fire's text.

## How to fix it

At https://claude.ai/code/routines, make a routine for this repo: paste the Command Center's routine prompt as its instructions ("See the cloud builders' setup" shows it), pick the repo and the model, keep the Default environment (Trusted network access reaches npm and GitHub; no org), and add an API trigger. Save it and copy its trigger id (trig_…): "Turn cloud builders on" records it. Then click Generate token and copy the token once: "Keep the routine's token" keeps it in the keychain, pasted when it asks.

More detail: [Salesforce docs](https://code.claude.com/docs/en/routines)

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
