# A routine for the repo

`B15.cloud-routine`

A script starts a cloud session only by firing a routine's API trigger (GH-69). The routine holds the repo, the model and the environment; acc sends each task in the fire's text.

## How to fix it

At https://claude.ai/code/routines, make a routine for this repo: paste acc's routine prompt as its instructions (acc cloud shows it), pick the repo and the model, keep the Default environment (Trusted network access reaches npm and GitHub; no org), and add an API trigger. Save it, copy its trigger id (trig_…) into: acc cloud enable --routine trig_…. Then click Generate token, copy the token once, and keep it with: acc cloud token (paste it on stdin).

More detail: [Salesforce docs](https://code.claude.com/docs/en/routines)

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does `acc doctor` in a terminal.
