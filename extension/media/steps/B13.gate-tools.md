# The required checks can run

`B13.gate-tools`

"Finish the task" waits for every required check to pass, and a check whose tool is missing can only report an error.

## How to fix it

**Do it** runs the exact command the check works out for this repo, in a terminal you can see.

More detail: the onboarding guide (**Read the guide**).

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
