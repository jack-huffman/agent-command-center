# The push guard is committed

`B15.cloud-guard`

A cloud session runs the repo's own .claude/settings.json hooks and not acc's plugin, so the guard that refuses a push to any branch but the task's is a script the repo carries (GH-69).

## How to fix it

**Do it** runs this in a terminal, so you see exactly what happens:

```bash
acc cloud enable
```

acc cloud enable writes .claude/hooks/acc-push-guard.mjs and its PreToolUse hook into .claude/settings.json. Commit both.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does `acc doctor` in a terminal.
