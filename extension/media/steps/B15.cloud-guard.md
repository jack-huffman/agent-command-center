# The push guard is committed

`B15.cloud-guard`

A cloud session runs the repo's own .claude/settings.json hooks and not acc's plugin, so the guard that refuses a push to any branch but the task's is a script the repo carries, and only what's committed reaches the cloud (GH-69).

## How to fix it

**Do it**: Turn cloud builders on. It runs in a terminal, so you see exactly what happens.

"Turn cloud builders on" writes .claude/hooks/acc-push-guard.mjs and its PreToolUse hook into .claude/settings.json. Commit both, and merge them into every branch a cloud session starts from.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
