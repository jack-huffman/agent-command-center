# The routine's token is in the keychain

`B15.cloud-token`

acc fires the routine with its bearer token, kept in this Mac's keychain and never in .acc/config.json or git (GH-69). The token is shown once, on the routine's page.

## How to fix it

On the routine's page, under its API trigger, click Generate token and copy it. Then, in a terminal: acc cloud token, and paste the token. It goes to the keychain under acc-cloud-routine, for this repo.

More detail: [Salesforce docs](https://code.claude.com/docs/en/routines#add-an-api-trigger)

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does `acc doctor` in a terminal.
