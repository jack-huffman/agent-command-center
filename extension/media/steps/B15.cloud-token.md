# The routine's token is in the keychain

`B15.cloud-token`

acc fires the routine with its bearer token, kept in this Mac's keychain and never in the project's settings or git (GH-69). The token is shown once, on the routine's page.

## How to fix it

On the routine's page, under its API trigger, click Generate token and copy it. Then, in a terminal, "Keep the routine's token" keeps it in the keychain under acc-cloud-routine, for this repo: paste the token when it asks.

More detail: [Salesforce docs](https://code.claude.com/docs/en/routines#add-an-api-trigger)

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
