# The scheduled task's token is kept

`B15.cloud-token`

The Command Center fires the scheduled task with its bearer token, never kept in the project's settings or git (GH-69): a Mac keeps it in its keychain, and Windows in VS Code, which hands it to the Command Center when the Command Center builds or reviews (T-145). The token is shown once, on the scheduled task's page.

## How to fix it

Do it opens Set up cloud builders; in The token: on the scheduled task's page, click Generate token (it's shown once), paste it in Token, and click Keep the token.

More detail: [Claude Code docs](https://code.claude.com/docs/en/routines#add-an-api-trigger)

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
