# Claude Code is signed in to claude.ai

`B15.cloud-login`

Sending a cloud builder a message (claude -p --cloud) needs the CLI signed in to the claude.ai account the scheduled task belongs to (GH-69).

## How to fix it

Do it opens Set up cloud builders; in Sign in: Do it runs Claude Code's sign-in in a terminal. Sign in with the claude.ai account that owns the scheduled task: an API key isn't enough for cloud sessions.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
