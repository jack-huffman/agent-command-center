# Claude Code is signed in to claude.ai

`B15.cloud-login`

Sending a cloud builder a message (claude -p --cloud) needs the CLI signed in to the claude.ai account the routine belongs to (GH-69).

## How to fix it

**Do it** runs this in a terminal, so you see exactly what happens:

```bash
claude auth login
```

Sign in with the claude.ai account that owns the routine. An API key isn't enough for cloud sessions.
