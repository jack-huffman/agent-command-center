# Python 3.10 or later, for Code Analyzer

`A1.python`

Code Analyzer's Flow engine runs on Python 3.10 or later, as Salesforce's Code Analyzer setup page says. Without it, that engine is turned off in code-analyzer.yml.

## How to fix it

**Do it** runs the line for your system in a terminal, so you see exactly what happens:

On a Mac:

```bash
brew install python
```

On Windows:

```powershell
winget install 9NQ7512CXL7T -e --accept-package-agreements --disable-interactivity; if ($?) { py install --configure -y }
```

On Linux:

```bash
sudo apt-get install python3
```

On Windows, after it installs, restart VSCode: a tool installed while VSCode is open isn't on its PATH until VSCode restarts.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
