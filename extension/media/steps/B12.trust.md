# Claude Code trusts the repo for background agents

`B12.trust`

Background agents start in the main checkout, and Claude Code only starts one in a folder you've trusted. VSCode's own Claude sessions don't record this, so it takes one run of claude in a terminal.

## How to fix it

**Do it** runs this in a terminal, so you see exactly what happens:

```bash
claude
```

In the terminal that opens, accept the "trust this folder" prompt, then type /exit.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does `acc doctor` in a terminal.
