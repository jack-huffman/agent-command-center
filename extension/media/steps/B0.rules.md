# Copied-in rules are current

`B0.rules`

A team's shared rules are copied into .acc/rules/, each with where it came from (GH-108), and agents read only those copies. This says when a source has changed since its copy. It never copies one in again: that is yours to choose.

**Import rules…** is here whatever the step shows.

## How to fix it

**Do it** runs the exact command the check works out for this repo, in a terminal you can see.

More detail: the onboarding guide (**Read the guide**).

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does `acc doctor` in a terminal.
