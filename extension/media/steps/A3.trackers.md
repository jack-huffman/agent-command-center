# Trackers connected

`A3.trackers`

The Tasks board and ticket pages read Jira and GitHub directly (D-026). Jira needs your API token once; GitHub works through gh.

## How to fix it

In VSCode: Command Palette → "Agent Command Center: Connect to Jira", with an API token from id.atlassian.com. For a GitHub Project's columns, run gh auth refresh -s project as the repo's account.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does `acc doctor` in a terminal.
