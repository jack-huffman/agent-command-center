# Trackers connected

`A3.trackers`

The Tasks board and ticket pages read Jira, Azure DevOps and GitHub directly (D-026), each signed in for this repo only (D-027).

## How to fix it

In VSCode: Command Palette → "Agent Command Center: Add a tracker…" (or "Sign in to a tracker" if it's already in the config). For a GitHub Project's columns, run gh auth refresh -s project as the repo's account.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does `acc doctor` in a terminal.
