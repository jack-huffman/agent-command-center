# README names every environment

`B10.readme`

Anyone opening the repo sees which branch is which org, and how changes flow.

## How to fix it

**Do it**: Write the README's environments table. It runs in a terminal, so you see exactly what happens.

"Do it" writes the environments table and promotion flow between markers in README.md, leaving the rest as it is. Run it again after changing the environments.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
