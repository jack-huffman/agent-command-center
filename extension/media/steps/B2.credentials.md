# git pushes as the right account

`B2.credentials`

gh's own credential helper ignores the username and uses the active account, so a repo can silently push as the wrong one.

## How to fix it

**Do it** runs the exact command the check works out for this repo, in a terminal you can see.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does `acc doctor` in a terminal.
