# The tools the project's checks need

`B13.tools`

Some projects' checks need a tool on this machine that npm install doesn't bring, such as a pinned browser to draw screenshots with. The project lists each in its config, with a command that checks for it and one that sets it up.

## How to fix it

**Do it** runs the exact command the check works out for this repo, in a terminal you can see.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
