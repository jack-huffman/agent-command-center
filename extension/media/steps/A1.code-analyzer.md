# Salesforce Code Analyzer

`A1.code-analyzer`

The `static` check runs `sf code-analyzer`, Code Analyzer 5.

## How to fix it

**Do it** runs this in a terminal, so you see exactly what happens:

```bash
sf plugins install code-analyzer
```

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
