# Baseline manifest

`B5.baseline`

Every branch is retrieved with the same component list, so a diff between branches is real drift.

## How to fix it

**Do it** runs this in a terminal, so you see exactly what happens:

```bash
acc setup baseline
```

"Do it" lists the components on every environment branch with sf, and writes the union to manifest/baseline-package.xml. Commit it on each branch.

More detail: the onboarding guide (**Read the guide**).

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does `acc doctor` in a terminal.
