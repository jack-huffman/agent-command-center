# Salesforce CLI

`A1.sf`

Validation, retrieves and org checks use sf.

## How to fix it

**Do it** runs the line for your system in a terminal, so you see exactly what happens:

On a Mac:

```bash
npm install -g @salesforce/cli
```

On Windows:

```powershell
npm install -g @salesforce/cli
```

On Linux:

```bash
npm install -g @salesforce/cli
```

On Windows, after it installs, restart VSCode: a tool installed while VSCode is open isn't on its PATH until VSCode restarts.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
