# Logged in to GitHub

`A2.gh-login`

Each repo uses its own account through `gh auth token -u`. Never `gh auth switch`, which changes every session.

## How to fix it

"Do it" opens VSCode's GitHub sign-in: pick this repo's account, or add it, and gh gets that login, with access to GitHub Projects for the board. gh's active account stays as it was. In a terminal: gh auth login.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
