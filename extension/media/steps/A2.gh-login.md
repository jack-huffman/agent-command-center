# Logged in to GitHub

`A2.gh-login`

Each repo uses its own account through `gh auth token -u`. Never `gh auth switch`, which changes every session.

## How to fix it

**Do it** runs this in a terminal, so you see exactly what happens:

```bash
gh auth login
```

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does `acc doctor` in a terminal.
