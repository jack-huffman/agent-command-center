# Java 11 or later, for Code Analyzer

`A1.java`

Code Analyzer's PMD and CPD engines run on a Java Development Kit, version 11 or later, as Salesforce's Code Analyzer setup page says.

## How to fix it

**Do it** runs the line for your system in a terminal, so you see exactly what happens:

On a Mac:

```bash
brew install --cask temurin
```

On Windows:

```powershell
winget install --id EclipseAdoptium.Temurin.25.JDK -e
```

On Linux:

```bash
sudo apt-get install openjdk-21-jdk
```

On Windows, after it installs, restart VSCode: a tool installed while VSCode is open isn't on its PATH until VSCode restarts.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
