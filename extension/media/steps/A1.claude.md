# Claude Code CLI with background sessions

`A1.claude`

Builders run as `claude --bg` sessions (D-009). The VSCode extension ships its own copy, so the terminal CLI can fall far behind.

## How to fix it

**Do it** runs this in a terminal, so you see exactly what happens:

```bash
claude update
```

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does `acc doctor` in a terminal.
