# Claude Code CLI with background sessions

`A1.claude`

Builders run as `claude --bg` sessions (D-009). The VSCode extension ships its own copy, so the terminal CLI can fall far behind.

## How to fix it

**Do it** runs this in a terminal, so you see exactly what happens:

```bash
claude update
```

If it isn't installed yet, the line for each system:

On a Mac:

```bash
brew install --cask claude-code
```

On Windows:

```powershell
irm https://claude.ai/install.ps1 | iex
```

On Linux:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

On Windows, after it installs, restart VSCode: a tool installed while VSCode is open isn't on its PATH until VSCode restarts.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
