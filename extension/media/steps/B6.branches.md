# A branch for every environment

`B6.branches`

Each environment has its own branch, named after it (D-015).

## How to fix it

**Do it**: Make the environment branches. It runs in a terminal, so you see exactly what happens.

"Do it" makes each missing branch: production's from this checkout, then each sandbox's from it, each retrieved from its own org (read only). Nothing is pushed until you push it.

More detail: the onboarding guide (**Read the guide**).

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
