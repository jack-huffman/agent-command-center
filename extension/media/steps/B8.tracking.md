# Developer sandboxes are source tracked

`B8.tracking`

A Developer sandbox is tracked only if tracking was on when it was created, or switched on inside it afterwards.

## How to fix it

Log in to the sandbox: Setup → Sandbox Settings → Enable Source Tracking in This Sandbox.

**Open in Salesforce** opens Setup in the right org.

More detail: [Salesforce docs](https://developer.salesforce.com/docs/platform/sfdx-dev/guide/sfdx-setup-enable-source-tracking-sandboxes.html)
