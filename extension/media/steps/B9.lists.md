# Environment-specific and known-drift lists

`B9.lists`

Environment config is never promoted or deployed (D-016), and drift checks need to know what differs by design.

## How to fix it

**Do it**: Draft the drift lists. It runs in a terminal, so you see exactly what happens.

"Do it" drafts both lists from how each sandbox's branch differs from production's, and names the differences neither explains. It never overwrites a list you have.

More detail: the onboarding guide (**Read the guide**).

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
