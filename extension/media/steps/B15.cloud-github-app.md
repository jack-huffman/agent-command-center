# Claude can clone the repo from the cloud

`B15.cloud-github-app`

A cloud session clones the repo from GitHub and pushes its branch back, through the GitHub access connected to your claude.ai account: the Claude GitHub App on the repo, or /web-setup in a terminal (GH-69).

## How to fix it

Do it opens Set up cloud builders; in GitHub access: Install the app opens the Claude GitHub App, to add this repo. Or run /web-setup in a claude session, which the Command Center can't see: then tick I've done this.

More detail: [Claude Code docs](https://code.claude.com/docs/en/claude-code-on-the-web#github-authentication-options)

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
