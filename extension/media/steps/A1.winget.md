# winget (on Windows)

`A1.winget`

On Windows, git, Node, the GitHub CLI, Java and Python are installed with winget, which comes in Microsoft's App Installer.

## How to fix it

**Do it** runs this in a terminal, so you see exactly what happens:

```bash
Add-AppxPackage -RegisterByFamilyName -MainPackage Microsoft.DesktopAppInstaller_8wekyb3d8bbwe
```

If App Installer isn't installed at all, get it from https://apps.microsoft.com/detail/9nblggh4nns1.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
