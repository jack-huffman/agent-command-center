# Raised floors merge on their own

`B10.merge-floors`

Two tasks that both raised a floor change the same line of the floors file. With this set up, git keeps the better of each, so neither waits for a person. A floor a person relaxed still waits for one.

## How to fix it

**Do it** runs the exact command the check works out for this repo, in a terminal you can see.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
