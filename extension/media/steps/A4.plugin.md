# The Command Center's Claude Code plugin

`A4.plugin`

Its hooks keep each builder inside its own worktree and away from pushes, merges and deploys, and send it back to the finish line if it stops early. It also gives agents the Command Center's skills and its reviewer. It's installed once, for every Claude Code session, and does nothing in a repo without the project's settings.

## How to fix it

**Do it** runs this in a terminal, so you see exactly what happens:

```bash
claude plugin marketplace add https://github.com/jack-huffman/agent-command-center && claude plugin install acc@agent-command-center --scope user
```

Claude Code clones this private repo with your own git credentials, so accept the invitation to it first. Sessions already running don't load the plugin: start a new one.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
