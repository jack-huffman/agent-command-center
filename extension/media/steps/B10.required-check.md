# GitHub requires the checks autopilot waits for

`B10.required-check`

Autopilot merges a pull request only once the checks the project names pass on GitHub. When GitHub requires them too, a person merging on GitHub waits for them as well. The Command Center never changes this setting: the fix is a command you run.

## How to fix it

**Do it** runs the exact command the check works out for this repo, in a terminal you can see.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
