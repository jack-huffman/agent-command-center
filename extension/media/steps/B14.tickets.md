# The repo's ticket source

`B14.tickets`

The Tasks board shows this repo's own tickets: a Jira project, an Azure DevOps board or GitHub Issues, signed in for this repo only (D-027). If this repo keeps its tasks in acc alone, mark this done.

## How to fix it

"Do it" walks you through it in VSCode: pick Azure DevOps, Jira or GitHub Issues, sign in, then pick the project, team and board, and last which of its tickets are this repo's: an epic, labels or an area path, or the whole project. It writes them to this repo's .acc/config.json.

More detail: the onboarding guide (**Read the guide**).

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does `acc doctor` in a terminal.
