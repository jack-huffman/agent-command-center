# The repo's ticket source

`B14.tickets`

The Tasks board shows this repo's own tickets: a Jira project, an Azure DevOps board, a monday.com board or GitHub Issues, signed in on this machine for this repo, or for every project on the same site. If this repo keeps its tasks in acc alone, mark this done.

## How to fix it

"Do it" opens the Connect page in the Command Center: pick Jira, GitHub Issues, Azure DevOps or monday.com, sign in and test the connection, then pick the project or board, which of its tickets are this repo's (an epic, labels, an area path or a group, or the whole of it) and the board's columns. Save writes them to this repo's settings.

More detail: the onboarding guide (**Read the guide**).

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
