# Homebrew (on a Mac)

`A1.brew`

On a Mac, git, Node, the GitHub CLI, Claude Code, Java and Python are installed with Homebrew.

## How to fix it

**Do it** runs this in a terminal, so you see exactly what happens:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does **Check the setup**, from the command palette.
