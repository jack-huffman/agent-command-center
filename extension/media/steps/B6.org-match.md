# Each branch points at the right org

`B6.org-match`

A sandbox's name is in its URL, so the tool can prove a branch deploys where its name says (D-015).

## How to fix it

"Do it" checks each environment's org, lists the ones that need a login first, and opens Salesforce's login for the one you pick, at the URL its name implies. Nothing to type: you sign in in the browser.

---

The step ticks itself when its check passes. **Check** re-runs it at any time, and so does `acc doctor` in a terminal.
